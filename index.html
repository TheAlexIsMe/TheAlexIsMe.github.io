VOID RP — BIBLE & RULES

1. Respect & Behavior

Treat all members with respect. Zero toxicity, harassment, or non-RP clutter in public chats.

2. Claiming Purchases

Void RP is not responsible for external scam deals. All official packages bought here are claimed strictly via Discord support tickets.

3. Server Terminology (Bible)

Maintain character immersion at all times. In-city translations:

  • Downed: Needs medical assistance / EMS
  • Scuffed: Experiencing a game glitch
  • Headache: Frame drops / Lag
  • Head Pop: Disconnected or crashed
  • Tsunami: Daily scheduled server restart
  • In City: Logged into Void City
  • Taking the Train: Server Queue
  • Bahama'd: In-game ban

Strictly Banned Terms In-City:

Banned, Ticket, Staff, Admin, Scene, Clip, 90 seconds, Inject, Greenzone, Game, FiveM, GTA, Scripts, MLO, Metagame, RDM/VDM/FRP.
