Void RP Community Guidelines

1. Respect Everyone

Treat all members with respect. Zero harassment, bullying, or toxicity permitted.

2. No Spamming or Flooding

Keep channels clean. Avoid excessive tagging or unnecessary clutter.

3. Disclaimer

All clothing and graphic deals are between seller and buyer. Void RP is not responsible for external transactions.

4. In-City Terminology (Bible)

Ensure you maintain proper roleplay immersion at all times. Standard translations:

  • Downed: Needs EMS revival
  • Scuffed: Glitched/broken mechanics
  • Headache: Frame drops / Lag
  • Head Pop: Disconnected / Game Crash
  • Tsunami: Server Restart
  • In City: Online in server
  • Taking the Train: Server Queue
  • Bible: Server Rules
  • Bahama'd: Banned

Strictly Prohibited Terms (In-City):

Banned, Ticket, Staff/Admin, Scene, Clip, 90 seconds, Inject, Greenzone, Game, FiveM, GTA, Scripts, MLO, Metagame, RDM/VDM/FRP.
